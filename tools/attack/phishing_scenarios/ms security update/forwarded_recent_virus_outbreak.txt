A recent group of viruses have been released which put systems at         
risk.  These viruses exploit vulnerabilities in Internet Explorer
and Outlook.  These viruses destroy data on the local systems and
leak personal information.  The viruses targeting Microsoft Outlook
are particularly dangerous because they only require the recipient
to open the email message in order to execute.<br>
<br>
Anyone running Microsoft Windows XP, Vista, or 7 should download the
following patch and install it immediately, to patch the
vulnerabilities being exploited.<br>
<br>
<b>Instructions:</b><br>
<br>
1. Click on this link PHISHING_URL<br>
<br>
2. On the resulting web page, click the "Download" button.<br>
<br>
3. A dialog box will pop up (you may need pop-ups enabled).  Start the installation immediately by clicking the "Run" button.  The installation takes less then
4 minutes, runs in the background, and does not require a reboot.<br>
